# ASTRONEER 日本語攻略

ASTRONEER の攻略情報を日本語で整理する静的サイトです。

現在は Xenobiology / Galastropod 攻略を収録しています。

- `io/index.html` が Pages の日本語版本体です。
- 章立ては Galastropod Guide の攻略順に対応させています。
- 本文は外部ガイドの逐語翻訳ではなく、公式Wiki・公式パッチノートで確認した内容を日本語で独自に整理しています。
- 画像ファイルは複製せず、Steam Community / Official Astroneer Wiki など原典へのリンクで参照します。
- `.github/workflows/validate.yml` が `/io/` の必須構造と「画像をローカルに置かない」方針を検証します。
