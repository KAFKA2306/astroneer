惑星コア

惑星コアのGateway Engine。地表Gatewayを少なくとも1つ起動後、惑星固有Resourceを投入して有効化します。

要点

  • 各Gateway Engineは惑星固有Resourceを1個要求し、Geometric Triptychを生成します。
  • Sylva Quartz / Desolo Zinc / Calidor Explosive Powder / Vesania Graphene / Novus Silicone / Glacio Diamond / Atrox Hydrogenです。
  • Triptychを反対側Slotに置くとEngineが起動しOdd Stoneを使えるようになります。
