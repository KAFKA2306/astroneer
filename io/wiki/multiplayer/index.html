マルチプレイヤー

他のプレイヤーと同じセーブ世界を探索・建築できる協力プレイ機能です。

要点

  • ホスト型 Co-op（Listen Server）は最大4人、Dedicated Server は最大8人として案内されています。
  • 接続するプレイヤーは同じゲームバージョンを使う必要があります。
  • Official Wiki は Dedicated Server 情報の一部を古い情報として警告しているため、プロバイダー別互換表は正本化しません。
