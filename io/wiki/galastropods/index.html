1. 開始方法

  1. ミッション Bait & Switch を進め、Sphalerite（閃亜鉛鉱）×3 を集める。
  2. 報酬の Strange Object を受け取る。
  3. Sylva の安全な地表に設置して起動し、Xenobiology Lab を出現させる。出現時には周辺にデブリも生成されるため、拠点の密集地から少し離して置く。
  4. ラボ周辺の Oxygenator を取り付ける。
  5. ラボへ電力を供給する。
  6. Data Log を操作し、追跡機能を有効化する。
ラボは Galastropod の検証にも使います。捕獲後は各個体をラボの指定スロットに取り付けて解析し、次の追跡ミッションを解放していきます。進行中には追加電力に加え、Signal Boost で EXO Chip ×1、Overcharged で EXO Chip ×2、合計3個が要求されます。

共通の捕獲手順

  1. 対象惑星で、その種の Shell を5個スキャンする。
  2. ミッション報酬から Empty Terrarium を受け取る。
  3. テラリウムへ 土入り Small Canister + 惑星ごとの資源 + 指定植物の Seed をセットする。
  4. 完成したテラリウムへ Small Trumpet Horn または Small Squeaker Horn を取り付けて呼び出す。
  5. 出現した Galastropod の近くで指定回数ダンスする。
  6. 十分になついたら、地面に置いたテラリウムで回収する。
  7. ラボへ持ち帰り、検証スロットに装着する。

9. ミッション完了

7匹すべてを捕獲・解析したら、まず All Together Now で Data Log から Sonic Array Hatch を開き、Xenobiology Lab 上部の Sonic Array に7匹すべてを配置します。短い歌の演出が再生されます。

All Together Now の報酬は QT-RTG ×2 と Lab Suit。続く Final Entry で Data Log の新しい記録を確認し、報酬として RTG ×1 を受け取ります。

10. 餌と能力の使い方

  • Galastropod は Seed を食べると固有能力が有効になります。通常の Seed では 10分、好物では 30分 持続します。
  • テラリウム上部のリングは能力が有効な間は青色になります。
  • Princess・Bestefar・Enoki は正しい装着位置で使う必要があります。Princess と Enoki はバックパック、Bestefar は Terrain Tool。誤った位置ではリングが赤く表示されます。
  • 使用していないときに常時餌を与え続ける必要はありません。
  • ミッション由来の重要アイテムを紛失した場合は、Landing Pad の Mission Log から再取得できるものがあります。
  • Galastropod は Gravity Globe の座席にも置けます。
